# Project Lifecycle Skill — v0.2.0

**An [Intelligenza Umana](https://github.com/fabiozagaria/intelligenza-umana) project.** See the [official project registry](https://github.com/fabiozagaria/intelligenza-umana/blob/main/docs/PROJECT_REGISTRY.md).
Skill riutilizzabile per governare progetti con agenti AI. Il metodo vive qui; il contesto vive nella repository di destinazione.

## Utilizzo
Leggere [SKILL.md](SKILL.md), indicare la repository e scegliere bootstrap, resume, handoff, audit, sync, migrate, status, plan o decision. Le operazioni sono istruzioni per agenti, non comandi CLI. Consultare [integrazioni Codex](integrations/codex/README.md) e [Claude](integrations/claude/README.md). Nessuna dipendenza runtime.

## Stato
Prototipo documentale; installazione nativa e test reali ancora da verificare. Distribuito con licenza [MIT](LICENSE).
