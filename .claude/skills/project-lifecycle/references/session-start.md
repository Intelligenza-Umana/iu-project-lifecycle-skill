# Inizio sessione
Leggi istruzioni applicabili, HANDOFF, README e riferimenti pertinenti. Controlla branch, git status, commit recenti e artefatti reali. Non sovrascrivere modifiche locali. Riassumi obiettivo, stato verificato, discrepanze, blocchi e prossima azione.

Applica [integrità del contesto](context-integrity.md), identifica fonti autorevoli e impatto prima di modificare.

Quando riprendi un risultato di test dal precedente HANDOFF, verifica a quale stato del codice si riferisce. Se mancano evidenze o il codice interessato è cambiato, indica che il risultato attuale è da verificare.
